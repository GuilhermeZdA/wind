# Definição de Pronto (Definition of Done)

Uma tarefa só é considerada **Concluída** quando atender a **todos** os critérios abaixo:

- [ ] **Código revisado e aprovado** por outro membro do time (Code Review).
- [ ] **Todos os critérios de aceite** da issue foram atendidos.
- [ ] **Testes unitários** escritos cobrindo os critérios de aceite e as regras principais.
- [ ] **100% dos testes passando** no ambiente de CI, com meta inicial de **70% de cobertura** no código novo.
- [ ] **Funcionalidade validada** e pronta para ser apresentada na Sprint Review (demo).

## Depois do merge

- [ ] A issue foi fechada e o cartão está em **Concluído**.
- [ ] A branch foi deletada.
- [ ] A documentação foi atualizada, se necessário.
